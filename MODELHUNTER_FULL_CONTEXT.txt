## 1. REPOSITORY OVERVIEW

ModelHunter is an adversarial ML evaluation platform with a React frontend and FastAPI backend. It supports training/evaluating models (CNN, ResNet18, MobileNetV2) on datasets (MNIST, CIFAR-10, GTSRB) against 5 attacks (FGSM, PGD, CW, ZOO, HopSkipJump) with 4 defenses (adversarial training, ensemble, input preprocessing). Includes explainability (Grad-CAM, SHAP), automated evaluation mode, and report generation.

## 3. KEY BUG FIXES & CHANGES (vs submitted paper)

### 3.1 Robustness Scoring (backend/app/evaluation/metrics.py:156-175)
**Bug**: Original formula used `confidence_shift` directly without restricting to clean-correct samples.
**Fix**: `compute_metrics()` now computes confidence_shift ONLY over `clean_correct_mask` (lines 125-133).
**Formula**: `score = 0.4 * adv_acc + 0.3 * (100 - ASR) + 0.3 * max(100 - conf_shift, 0)`
**Thresholds**: ≤30 Weak, 30-60 Moderate, >60 Strong

### 3.2 AttackStats.record() (scripts/corrected_attacks.py:30-40)
**Bug**: `perturbation.flatten(1)` treated channels as batch dimension → wrong per-sample L∞/L2 stats.
**Fix**: Changed to `perturbation.detach().flatten()` for true per-sample norms.
**Impact**: All perturbation_stats in results/attacks/*.json now correct (n_samples=10000, not 30000).

### 3.3 run_experiments.py Path & pin_memory Fixes
- Line 32: `Path(__file__).resolve().parent / "backend"` → `parents[1] / "backend"`
- Line 239/241: `device == "cuda" or device.startswith("cuda")` → `str(device).startswith("cuda")`
- Epoch default: 10 → 30, Patience: 5 → 7

### 3.4 train_model() in model_service.py (lines 103-177)
- Added CosineAnnealingLR scheduler
- Added gradient clipping (max_norm=1.0)
- Changed optimizer from Adam to SGD with momentum=0.9, weight_decay=5e-4

### 3.5 Corrected Attacks (scripts/corrected_attacks.py vs backend/app/attacks/*)
| Attack | Original Issue | Corrected Implementation |
|--------|----------------|-------------------------|
| FGSM | Operated in normalized space, epsilon semantics wrong | Pixel space [0,1] → denormalize, attack, renormalize |
| PGD | Same normalized space issue | Pixel space with proper projection |
| CW | atanh on normalized inputs → NaN; used softmax → instability | atanh on clamped [1e-6, 1-1e-6]; logit-based hinge loss |
| ZOO | Leaf tensor issues; coordinate descent broken | Random vector stochastic approximation (finite-difference) |
| HopSkipJump | No real boundary search | Binary search to decision boundary + gradient estimation |

All attacks now verify L∞ and L2 perturbation budgets via AttackStats.

## 7. AUTOMATED MODE (Frontend + Backend)

### Backend: `/api/automated/run` (backend/app/api/automated.py)
1. **Step 1**: Clean baseline (no attack, no defense) → clean_accuracy
2. **Step 2**: Attack applied (full epsilon, no defense) → full metrics
3. **Step 3..N**: Same attack with each defense (adversarial_training, ensemble, input_preprocessing)

Returns step-by-step results with `best_defense` summary.

### Frontend: AutomatedMode.jsx
- Configuration panel: dataset, model, attack, epsilon, sample limit
- Runs sequence via `apiPost("/automated/run", {...})`
- Renders live timeline with RobustnessRing and metrics table
- Shows "Best vs Worst Defense" comparison
